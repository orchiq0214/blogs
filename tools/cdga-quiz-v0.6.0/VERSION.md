# CDGA 刷题工具版本

## v0.6.0

- 错题答对后不再消失：连续答对 3 次才标为已巩固，仍保留在曾错题复习范围。
- 错题测试覆盖全部曾错题，优先高危错题和待巩固题。

## v0.5.0

- 新增逐题统计：累计作答、正确、错误、正确率和最近结果。
- GitHub 同步改为启动合并本地与远端记录，并识别版本冲突后自动合并重试。

## v0.4.0

- 题目标签自动去重：章节、知识点、参考内容相同只显示一次。

## v0.3.0

- 支持导入并按章节筛选刷题。
- 题目卡片空白处左键下一题、右键上一题；选项和按钮不触发切题。
- 新建测试可随机打乱选项；同一套题会固定顺序，暂停或换设备后不变。

## v0.2.0

- 新增背题模式，可在测试中和考试模式无缝切换。
- 答题卡新增正确/错误状态：背题模式即时显示，考试模式提交后显示。
- 新增 PWA 支持，安卓浏览器可添加到主屏幕。
- 同步页默认填充 GitHub 用户名、仓库名、分支、题库路径和答题日志路径。

## v0.1.0

- 初始静态版：Markdown 题库、本地保存、GitHub 同步、测试记录、错题本。
